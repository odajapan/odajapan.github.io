プライバシーポリシー(座談会 アップロードツール)

このアプリは、座談会チャンネル(@news-zadankai)の運営者が、自分のチャンネルに動画をアップロードするためだけに使う個人用ツールです。

  • YouTube Data API で行うのは、運営者自身のチャンネルへの動画アップロード、再生リストへの追加、サムネイルの設定だけです。
  • 認証情報(OAuth トークン)は運営者のコンピュータ内にだけ保存し、第三者に提供・送信しません。
  • 運営者以外の利用者のデータを収集・保存・共有しません。
  • 本アプリは YouTube API サービスを使っています。Google のプライバシーポリシー: https://policies.google.com/privacy
  • 連絡先: YouTube チャンネルの概要欄をご覧ください。
